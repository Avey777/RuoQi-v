# rp2flutter

把摹客 RP（Mockplus）离线演示包中的原型页面转换为 Flutter widget。

## 用法

```bash
python3 frontend/tools/rp2flutter/convert.py
```

默认从 `frontend/apps/pc/platform/lib/管理后台/管理后台`（离线包解压目录）读取
`一账通(IDaaS/IAM)-运营管理后台` 模块，把全部页面生成到
`frontend/apps/pc/platform/lib/管理后台/<模块>/`，同时：

- 生成 `frontend/apps/pc/platform/lib/prototype_registry.dart`（页面注册表）；
- 把页面引用的图片复制到 `frontend/apps/pc/platform/assets/images/`；
- 页面可直接通过 `PrototypeViewer` 预览（尺寸、缩放、平移）。

可选参数：

```bash
python3 frontend/tools/rp2flutter/convert.py \
  --prototype <离线包目录> \
  --out-lib <目标 lib 目录> \
  --module "<原型模块名>" \
  --module-dir "<目标目录名>"
```

## 输出约定

- 每个原型页面对应一个 `<pageId>.dart`，类名为 `<pageId>Page`（非法字符去除，
  数字开头加 `P` 前缀）；文件名使用中文页面标题（如 `通用.dart`、`货币-编辑.dart`），
  同一目录下重名时自动加父级名称消歧；
- 页面为绝对定位的 `SizedBox + Stack + Positioned` 结构，与原型坐标一一对应；
- 图标使用 `boldIconFont` / `lightIconFont` 字体字形；
- 矢量 path 转成页面内联的 `CustomPainter`。

生成文件头部带有 `Generated by tools/rp2flutter/convert.py — do not edit by hand.`
标记，重新运行脚本即可整体重新生成。
