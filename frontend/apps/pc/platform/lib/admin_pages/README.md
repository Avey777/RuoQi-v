# admin_pages（系统管理）

按左侧菜单一个板块一个目录，目录名与菜单名一一对应，方便定位每个菜单下的页面：

| 目录 | 内容 |
| --- | --- |
| `设置/` | 通用、本地化、电子邮件、编码规则、短信、auth登录、验证消息 |
| `用户/` | 用户、角色 |
| `权限/` | 权限 |
| `菜单/` | 菜单 |
| `基础/` | 世界地理规划、地区&国家、导入地区、UTC、时区数据库、货币、历史汇率 |
| `语言/` | 多语言、翻译、导入、导出 |
| `日志/` | 验证、操作、登录、支付日志 |

- 七个菜单均已接入规范业务页（`DESIGN-consensus.md`）；页面内容按原型提炼，交互
  （表格 / 筛选 / 弹层面板 / 状态徽章）复用 `shared/` 与 `用户/user_management_widgets.dart`。
- `system_settings_dialog.dart`：系统管理入口弹窗（根目录）。
- `settings_content_dialog.dart`：内容区内嵌面板工具，供各菜单页面复用。
- `菜单/ 基础/ 语言/ 日志/` 目录下与菜单同名的 `.dart` 原型页（如 `货币.dart`）为
  原 Mockplus 转换产物，仅原型预览用，业务页接入后按需删除。
